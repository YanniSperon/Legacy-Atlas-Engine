# Legacy Atlas Engine

The original Atlas Engine

## All code written from early October 2019 to early December 2019. Git was rebased to change the commit authors because it was initially improperly configured.

Used as a means to teach myself graphics programming (through OpenGL) and C++.

Set myself a deadline at the end of my high school semester.

Implemented Bullet Physics, a scene editor, a basic 3D rendering engine (blinn-phong), post processing shaders, and a custom multithreaded 3D model loader.
